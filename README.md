# Homebrew Tap for Sacha

This is the official Homebrew tap for [sacha](https://github.com/Sachamama/sacha), a keyboard-first AWS TUI.

## Installation

```bash
brew tap sachamama/tap
brew install sacha
```

Or install directly:

```bash
brew install sachamama/tap/sacha
```

## Updating

```bash
brew update
brew upgrade sacha
```

## What is Sacha?

Sacha is a keyboard-first AWS Terminal User Interface (TUI) inspired by classic two-pane file managers. It helps you browse, search, and manage AWS resources directly from the terminal.

**Currently supports:**
- CloudWatch Logs: Search, multi-select, and tail multiple log groups
- S3: Browse buckets, download/delete files, preview content

For more information, visit the [main repository](https://github.com/Sachamama/sacha).
